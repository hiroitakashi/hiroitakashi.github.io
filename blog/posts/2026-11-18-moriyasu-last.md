**この記事の要点**

- 森保一監督のラストマッチとなった11月17日のパラグアイ戦（シンガポール）は、**1-2で敗戦**。前半に左CKから2失点し、終盤にA代表デビューの**福田師王**が1点を返しました。
- 2018年7月の就任から約8年、通算成績は**113試合77勝17分け19敗**。日本代表で初めて通算100試合を指揮した監督です。
- 来年3月からは**大岩剛監督**の新体制に。2027年1月に予定されていたアジアカップは約1年延期されました。

14日のブラジル戦で3-2の劇的勝利を挙げた直後だけに、「最後も勝って送り出したい」と見守った方も多かったはずです。ゆうべの試合の中身と、8年間の歩みを数字で振り返ります。

## 試合の流れ：CKから2失点、福田師王が意地の1点

日本はブラジル戦から、GK鈴木彩艶を除くスタメン10人を入れ替えて臨みました（サッカーキング）。

| 項目 | 内容 |
|---|---|
| 日時 | 2026年11月17日（火）22:10キックオフ（日本時間） |
| 会場 | シンガポール・ナショナル・スタジアム |
| 結果 | 日本 1-2 パラグアイ |
| 失点 | 2分 カセレス、40分 G・ゴメス（いずれも左CKから） |
| 得点 | 85分 福田師王（A代表デビュー戦で初ゴール） |
| 放送 | 日本テレビ系（TVer でも無料配信）、U-NEXT |

試合開始早々、左CKからフアン・ホセ・カセレスに決められ、40分にも同じく左CKからグスタボ・ゴメスに頭で押し込まれました。2本ともキッカーはディエゴ・ゴメスです（J.LEAGUE.jp、サッカーキング）。

日本の先発は、GK鈴木彩艶、DF菅原由勢・板倉滉・渡辺剛・鈴木淳之介、MF相馬勇紀・鈴木唯人・佐野航大・佐野海舟・坂元達裕、FW後藤啓介。ブラジル戦で決勝点を挙げた坂元が、この日は先発に名を連ねました。

追いかける日本は85分、カールスルーエ所属の22歳、福田師王がネットを揺らします（Goal.com）。代表キャップ0での招集から、デビュー戦で初ゴール。森保監督に贈る1点になりましたが、同点には届きませんでした。

## 森保監督の言葉：「選手たちは未来を見せてくれました」

試合後のインタビューで、森保監督は敗戦の悔しさと感謝の両方を口にしています（Goal.com）。

> ほぼシュートを打たれていなかった中で、試合の入り方やセットプレー2発でやられたことなど、もっと賢くゲームを進めなければいけなかったと思います

> 選手たちには本当に幸せな思いをさせていただいて、選手やスタッフに恵まれて幸せな時間を過ごせた

> 今日勝てなくて残念ですけど、選手たちは未来を見せてくれました

最後の会見では、大切にしてきた言葉として「万物育成」を挙げ、「◯◯ジャパンではなく、日本代表はずっとみんなの日本代表」と語りました（サッカーキング）。

## 数字で見る「森保ジャパン」の8年

| 項目 | 内容 |
|---|---|
| 就任 | 2018年7月（W杯ロシア大会のあと） |
| 最終戦 | 2026年11月17日 パラグアイ戦 |
| 通算成績 | 113試合 77勝17分け19敗 |
| 記録 | 日本代表史上初の通算100試合指揮、W杯2大会連続で指揮 |
| W杯カタール大会（2022年） | グループ1位通過、決勝トーナメント1回戦でクロアチアに1-1（PK1-3） |
| W杯北中米大会（2026年） | 1勝2分けの無敗・2位で通過、決勝トーナメント1回戦でブラジルに1-2 |
| 印象的な勝利 | 2026年3月、ウェンブリーでイングランドに1-0で歴史的初勝利（三笘薫） |

（出典：マイナビニュース／サッカーキングの結果まとめ）

77勝は、113試合のおよそ68%にあたります。今年のW杯では、ブラジル相手に後半アディショナルタイムの失点で敗れ、ベスト32で大会を終えました。それから数か月、11月14日の親善試合でそのブラジルに3-2で勝ったことは、8年間の締めくくりの1つとして記憶に残りそうです。

日本サッカー協会の宮本恒靖会長は「本当にこれだけ長くやってもらった監督は初めて」と語っています（サッカーキング）。

## これからの日本代表：大岩剛監督の新体制とアジアカップ延期

今後の予定は、次のように整理できます（サッカーキング）。

- **新監督**：来年3月から大岩剛監督の新体制が発足。大岩監督はロサンゼルス五輪を目指すU-21日本代表の監督も兼ねます。
- **アジアカップ**：2027年1月に予定されていたAFCアジアカップ（サウジアラビア）は、情勢悪化などの影響で約1年延期。新しい日程は2027年12月23日〜2028年1月21日とされています。
- **12月30日のキリンチャレンジカップ2026**：中止になりました。

つまり、日本代表の次の試合は来年3月、大岩新監督のもとでの初陣になる見込みです。

## まとめ

- 森保監督のラストマッチはパラグアイに1-2。CKからの2失点が響きました。
- それでも、デビュー戦の福田師王がゴールを決め、監督の言う「未来」をのぞかせました。
- 8年間で113試合77勝17分け19敗。来年3月からは大岩剛監督のもとで、新しい日本代表が始まります。

ブラジル戦の劇的勝利から3日。白星で送り出すことはできませんでしたが、8年間を数字で並べてみると、日本代表が積み重ねてきたものの大きさが見えてきます。3月から始まる大岩ジャパンの船出にも注目です。
