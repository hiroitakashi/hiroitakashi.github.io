- この30語の中から、**12月1日にトップテン**が発表されます。

年末が近づくと気になるのが「今年の流行語」です。11月5日に発表されたノミネート30語は、さっそくSNSのトレンドに上がり、「この言葉、知ってる？」と話題になっています。この記事では、30語をジャンルごとに分けて、それぞれの意味を短く紹介します（説明は出典の記事にもとづいています）。

## ネット・SNSから生まれた言葉

今年いちばん「意味が分からない」と言われていそうなのが、このグループです。

| 言葉 | 意味 |
|---|---|
| ドパガキ | 「ドーパミン中毒のガキ」を縮めたネットの俗語。短くて刺激の強いコンテンツに慣れ、集中力が続かない人を指したり、自分を笑うときに使ったりします。派生語に「ドパ中」「セロおじ」も |
| フレネミー | friend（友人）と enemy（敵）を合わせた造語。親しげにしながら、足を引っ張ってくる人のこと |
| ホビ垢 | 「ホビーアカウント」の略。若い世代を中心に、メインの「本垢」とは別に、推し活などの趣味用アカウントを持つ動き |
| setlog（セットログ） | 1時間ごとに約2秒の動画を撮り、1日分を1本にまとめる動画投稿型のSNS。Kstyleによると韓国発祥のアプリです |
| スマホ農場 | 「クリックファーム」とも。たくさんのスマホで「いいね」やフォロワー数、再生回数、広告のクリック数を不正に水増しする拠点や仕組み |
| 言語化 | 考えや気持ちを言葉ではっきり表すこと。関連する本が増え、使われる場面が広がりました |
| あかり、信じてるからな | 料理家・管理栄養士の長谷川あかりさんのレシピについて、ファンがSNSで期待と少しの不安を込めて投稿する言葉 |

| キオクシア | AI 向けの需要で株価が急上昇し、個人投資家の間で話題に。急落する場面もあり、「AIバブル」を警戒する声も出ました |

| 青切符 | 2026年4月から自転車にも使われるようになった交通反則通告制度（反則金の切符）。16歳以上が対象です |

## 今年の候補から見えること

オリコンの記事によると、選考する側は、物価高や中東情勢、異常気象など**不安を感じさせる言葉が多い**一方で、「ボンドロ」「好きすぎて滅！」「なんとかなれーッ」のように**ほっとさせてくれる言葉**も候補入りした、と見ています。

並べてみると、たしかに今年の30語は「暮らしの心配ごと」と「小さな楽しみ」がはっきり分かれています。

- **心配ごと系**：NISA貧乏、ナフサ、酷暑日、警戒レベル5、AI暴走 など
- **癒やし・楽しみ系**：ボンドロ、スクイーズ、ちいかわ（現象）、パンチくん、好きすぎて滅！ など
- **ルールが変わった系**：青切符、消費税1％、警戒レベル5、酷暑日 など

また、「ドパガキ」「フレネミー」「ホビ垢」「setlog」のように、若い世代の SNS から広がった言葉が多いのも今年の特徴です。家族や職場で「どれ知ってた？」と話のタネにしてみるのも楽しいかもしれません。
