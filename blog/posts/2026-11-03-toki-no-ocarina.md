**この記事の要点**

- 任天堂のNintendo Switch 2用ソフト『ゼルダの伝説 時のオカリナ』が、**あさって11月5日（木）**に発売されます。
- 1998年にNINTENDO 64で発売された名作を元にした**フルリメイク**で、希望小売価格は**パッケージ版8,980円・ダウンロード版7,980円（いずれも税込）**です。
- カメラを自由に回せる、好きなときにジャンプできる、ボタン長押しで「ダッシュ」など、遊びやすさを高める新要素が加わりました。

文化の日の連休明け、今週いちばん注目のゲームの新作です。「ゼルダの伝説」シリーズは今年で40周年。その記念の年に、シリーズの中でも特に評価の高い一本がよみがえります。発売前に知っておきたいことを、任天堂の公式サイトとゲーム専門メディアの記事をもとにまとめました。

## 発売日・価格・対応機種

| 項目 | 内容 |
|---|---|
| タイトル | ゼルダの伝説 時のオカリナ |
| 対応機種 | Nintendo Switch 2 |
| 発売日 | 2026年11月5日（木） |
| パッケージ版 | 8,980円（税込） |
| ダウンロード版 | 7,980円（税込） |
| 年齢区分 | CERO B（12才以上対象） |
| 発売元 | 任天堂 |

価格は任天堂公式サイトの希望小売価格です。パッケージ版とダウンロード版の差は1,000円。通販サイトでは予約価格が下がっている例もあり、ASCII.jpの10月30日の記事では、Amazon.co.jpでパッケージ版が**7,755円（14％オフ）**で予約を受け付けていたと伝えています。値段は日々変わるので、買う前に各店で確かめてください。

発売日が発表されたのは、9月8日に配信された「ゼルダの伝説40周年 Direct」でした。Game*Sparkによると、それまでは「年内発売」とだけ明かされていたため、ここで初めて具体的な日付が決まりました。

## どんなゲーム？――「時を超え、少年は勇者に。」

公式サイトのキャッチコピーは「時を超え、少年は勇者に。」。主人公は、森で唯一妖精を持たない少年リンクです。

- **2つの時代を行き来する冒険**：こども時代とおとな時代を行き来しながら、ハイラルの各地を旅します。
- **謎解き**：手に入れたアイテムと「ひらめき」でダンジョンの仕掛けを解いていきます。
- **剣と盾の戦い**：公式サイトの言葉では「剣で攻め、盾で防ぎ、隙を突く。」。
- **オカリナ**：タイトルにもなっている、特別な力を持つ楽器。奏でるメロディが冒険のカギになります。

原作は1998年にNINTENDO 64で発売された作品です。今回はそれを元にした**フルリメイク**で、Game*Sparkは見た目を「一新しながらも懐かしさを感じられるような」デザインを目指したと伝えています。

## 新しくなったところ

40周年 Directで紹介された主な変更点を、Game*SparkとASCII.jpの記事からまとめます。

| 新要素 | どう変わる？ |
|---|---|
| カメラ操作 | カメラを自由に回せるように |
| ジャンプ | 好きなタイミングでジャンプできる |
| ダッシュ | 移動中にボタンを押し続けると移動速度が上がる |
| 時間の流れ | あらゆる場面で時間が常に流れる |
| オカリナの音声入力 | 本体のマイクに向かって鼻歌を歌うと、作中のオカリナを演奏できる |
| 時の軌跡 | これまでの物語の流れを振り返られる新機能 |
| タペストリー | 物語を進めるほど絵柄が埋まっていく |

敵に狙いを定める「注目システム」（ロックオンのような機能）は、原作から引き継がれています。ASCII.jpは、スマートフォンと連携するサービスにも対応すると紹介しています。

特に話題になったのが**「鼻歌でオカリナ」**です。Directの映像では、鼻歌のほか電子オカリナの演奏にも反応する様子が披露されました。原作を遊んだ世代にとっては、あのメロディを自分の声で奏でられるのはうれしいところでしょう。

## 40周年の記念本体とアクセサリーも発売中

ソフトに先がけて、10月29日（木）には「ゼルダの伝説」40周年を記念した特別デザインの本体とアクセサリーが発売されています（価格はいずれも税込の希望小売価格）。

| 商品 | 価格 |
|---|---|
| Nintendo Switch 2 ゼルダの伝説 40周年 アニバーサリーエディション | 62,980円 |
| Nintendo Switch 2 Proコントローラー（40周年 アニバーサリーエディション、ディスプレイスタンド付き） | 12,980円 |
| Nintendo Switch 2 キャリングケース（40周年 アニバーサリーエディション、画面保護シート付き） | 3,980円 |

注意したいのは、記念本体に**『時のオカリナ』のソフトは付いていない**ことです（任天堂公式サイトに明記）。本体は特別デザインの本体・Joy-Con 2・ドックなどのセットで、日本語・国内専用。ゲームは別に買う必要があります。

## 買う前のチェックポイント

- **Switch 2専用です。** 初代Nintendo Switchでは遊べません。
- **パッケージ版か、ダウンロード版か。** 希望小売価格はダウンロード版のほうが1,000円安くなっています。人に貸したり、遊び終えて手放したりしたいならパッケージ版が向いています。
- **早期購入特典は数量限定。** 販売店ごとにオリジナルグッズが付くキャンペーンがありますが、すでに終わっている店もあります。各店の案内で確かめてください。
- **連休明けの木曜発売。** 店頭で買う場合は、取り扱いの時間や在庫を事前に確かめておくと安心です。

## まとめ

『ゼルダの伝説 時のオカリナ』は、11月5日（木）にNintendo Switch 2で発売されます。価格はパッケージ版8,980円、ダウンロード版7,980円（税込）。28年前の名作が、カメラ操作やダッシュ、鼻歌で奏でるオカリナなど、今の遊びやすさをまとってよみがえります。原作を遊んだ人には懐かしく、初めての人にはシリーズの原点のひとつにふれる良い機会になりそうです。
