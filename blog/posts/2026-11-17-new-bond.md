**この記事の要点**

- Amazon MGMスタジオが現地時間11月16日、**ロバート・パティンソンさん（40）を新しいジェームズ・ボンドに起用**すると正式に発表しました。正規シリーズで**7人目**のボンドです。
- 新作は正規シリーズの**26作目**。監督は『DUNE／デューン』の**ドゥニ・ヴィルヌーヴ**、脚本は**スティーヴン・ナイト**、製作は**エイミー・パスカル**と**デヴィッド・ハイマン**です。
- 題名・撮影開始・公開日は**まだ発表されていません**。

日本では17日の未明にこのニュースが伝わり、朝から「007」「新ボンド」「パティンソン」といった言葉が一気に検索されています。ダニエル・クレイグさんの起用が発表された2005年10月から数えて21年ぶりのボンド交代です。発表された内容を、出典で確かめられたことだけにしぼって整理します。

## 何が発表されたのか

Amazonの公式ニュースによると、発表の主な中身は次のとおりです。

| 項目 | 内容 |
|---|---|
| ボンド役 | ロバート・パティンソン（イギリス出身、40歳） |
| 監督 | ドゥニ・ヴィルヌーヴ |
| 脚本 | スティーヴン・ナイト |
| 製作 | エイミー・パスカル（Pascal Pictures）、デヴィッド・ハイマン（Heyday Films） |
| 製作総指揮 | タニア・ラポワント |
| 作品の位置づけ | 正規シリーズ26作目（ABC News） |
| 題名・公開日 | 未発表 |

パティンソンさんは公式発表のなかで「この役が夢のようだと言っても、まだ言い足りない」という趣旨のコメントを寄せています。ヴィルヌーヴ監督も「撮影を始めるのが待ちきれない」と話しており（シネマトゥデイ、THR Japan）、シネマトゥデイによると、『007』の公式SNSでは新しいボンドのファーストルックも公開されました。

THR Japanが伝えた米ハリウッド・リポーターの報道では、パティンソンさんに起用が伝えられたのは日曜日の朝で、ヴィルヌーヴ監督が自ら知らせたとのことです。

## 歴代ボンドの顔ぶれ

1962年の『ドクター・ノオ』から続く正規シリーズで、ボンドを演じたのはこれまで6人。パティンソンさんが7人目になります。

| 代 | 俳優 |
|---|---|
| 初代 | ショーン・コネリー |
| 2代目 | ジョージ・レーゼンビー |
| 3代目 | ロジャー・ムーア |
| 4代目 | ティモシー・ダルトン |
| 5代目 | ピアース・ブロスナン |
| 6代目 | ダニエル・クレイグ |
| 7代目 | **ロバート・パティンソン** |

6代目のクレイグさんは2006年の『007／カジノ・ロワイヤル』から5作に出演し、2021年の『007／ノー・タイム・トゥ・ダイ』で役を終えました。ABC Newsによると、この作品は世界で7億5,000万ドルを超える興行収入をあげています。それから5年、次のボンドが誰になるのかはずっと注目の的でした。

なお、1967年の『007／カジノ・ロワイヤル』（デヴィッド・ニーヴン主演）はパロディ作品で、正規シリーズには数えません（THR Japan）。

## ほかの候補は誰だったのか

THR Japanとシネマトゥデイが伝えた米国の報道によると、10月下旬にスクリーンテストが行われ、パティンソンさんのほかに**カラム・ターナー、ジャック・ロウデン、ジョシュ・オコナー、ニコラス・ホルト**の各氏が候補だったとされます。いずれも報道ベースで、公式に発表された選考の経過ではありません。

長年うわさに上がったイドリス・エルバさんやトム・ハーディさん、ヘンリー・カヴィルさんらについては、THR Japanが「多くの報道は選考対象だったことを裏付けるものではなかった」と注記しています。

## なぜ今、Amazonが発表したのか

『007』の映画は長く、バーバラ・ブロッコリさんとマイケル・G・ウィルソンさんが製作を率いてきました。Amazonの発表によると、**2025年3月**にAmazon MGMスタジオが2人との新しい合弁事業をまとめ、ジェームズ・ボンドの映画づくりの主導権（クリエイティブ・コントロール）を得ています。今回の配役は、その新体制で初めての大きな発表です。

## パティンソンさんはどんな俳優？

パティンソンさんは19歳のとき、『ハリー・ポッターと炎のゴブレット』（2005年）のセドリック・ディゴリー役で注目されました。その後の主な出演作は次のとおりです（Amazon、ABC Newsより）。

- 『トワイライト』シリーズ（2008〜2012年）のエドワード・カレン役
- 『THE BATMAN－ザ・バットマン－』（2022年）でバットマン役。続編は現在撮影中で、2028年公開予定（ABC News）
- 『ミッキー17』
- 『デューン 砂の惑星PART3』（フェイスダンサー役）

ヴィルヌーヴ監督とは『デューン 砂の惑星PART3』ですでに組んでおり、同作は**12月18日に日米同時公開**の予定です（シネマトゥデイ）。新ボンドを待つあいだ、ひと足先に「監督と主演」の組み合わせをスクリーンで確かめられることになります。

## まだ決まっていないこと

今回の発表に含まれていないものも、はっきりさせておきます。

- 新作の**題名**
- **撮影の開始時期**と**公開日**
- 日本での**配給**
- ほかの出演者（M、Q、マネーペニーなど）

ヴィルヌーヴ監督は「撮影を始めるのが待ちきれない」と話していますが、具体的な日程はまだ示されていません。公開日が決まれば、また大きな話題になるはずです。
